# Império Auto

Apresentação digital para serviços de estética automotiva.

**Demonstração:** https://emperio-estetica-automotiva.vercel.app

## Objetivo

Divulgar os serviços e facilitar o contato com a empresa. O conteúdo comercial deve permanecer alinhado às informações confirmadas pelo responsável.

## Situação do repositório

O site está publicado, mas os arquivos da aplicação ainda não foram organizados aqui. O GitHub só mostrará as linguagens quando o código for versionado neste repositório.

## Conteúdo

Antes de atualizar a página, confirmar serviços, contatos, horários e autorização para uso das imagens.
